# Contributing

Developer feedback, bug reports, and suggestions are welcome through GitHub
Issues.

Do not submit a pull request unless a Torah Pod maintainer has asked for one.
If a maintainer asks you to contribute code, you must have the right to submit
it and grant Torah Pod a perpetual, worldwide, royalty-free right to use,
modify, distribute, sublicense, and relicense that contribution.

The repository's rights notice applies to material first published after July
19, 2026. Earlier MIT-licensed releases remain available under their original
terms.
